# tiny-stack-vm

[![make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122/badge.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

A tiny stack virtual machine for [make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): one `main.ts` (Node 22) that runs every program of the bounty ISA and answers with exactly the bytes it writes and the exit code it ends with.
